Flask-WTF による CSRF 対策

このフォームは form.hidden_tag() により、 CSRF トークンが自動で埋め込まれます。

{% with messages = get_flashed_messages(with_categories=true) %} {% for category, message in messages %}

[{{ category }}] {{ message }}

{% endfor %} {% endwith %}
{{ form.hidden_tag() }}

{{ form.name.label }}
{{ form.name(size=24) }}

{{ form.message.label }}
{{ form.message(size=40) }}

{{ form.submit() }}

確認手順

  1. 通常のフォーム送信は成功します。
  2. 次のコマンドでトークンなし POST を送ると 400 になります。
curl -X POST http://127.0.0.1:5000/ -d "name=evil&message=attack"
